# Orari Circumvesuviana By Baffo

Tutte le fermate della Circumvesuviana **Napoli – Sorrento**, ognuna collegata al tabellone partenze in tempo reale di EAV (treno, destinazione, binario, orario e ritardo).

Sito: https://baffo0.github.io/Orari-Circumvesuviana-By-Baffo/

I tabelloni sono quelli ufficiali EAV: `https://orariotreni.eavsrl.it/teleindicatori/?stazione=<numero>`.
I numeri delle stazioni sono nell'elenco `STOPS` dentro `index.html`.
